AXON BODY 3 执法记录仪模组

GTASA 安卓端 SO 插件，复刻 AXON BODY 3 执法记录仪，用于警察角色扮演。

项目介绍

AXON BODY3 v3.1.1b 详细介绍 这是 GTASA 安卓端的 SO 插件，复刻现实里的 AXON BODY3 胸挂执法记录仪，专门用于警察角色扮演。 主要功能： 1. 胸挂相机，模拟真实记录仪跑动晃动，支持持枪、车内视角。 2. 记录仪机身水印读取本地时间，警员编号、电量位置可单独调整。 3. 游戏打开只显示悬浮球，需手动开启，位置自动记忆。 4. 内置完整设置菜单，可一键恢复默认参数。 5. 水印开关有提示音，出错有详细报错。 Beta 测试版，细节待完善，每次进游戏需手动激活。

GTASA-UI Redo界面重置

UI Redo 1.1.0 作者：流王 把 GTA SA 手游的开场、菜单、加载界面整体重做，图片、音频、文字和时间均可自定义，同时保留原版游戏功能。 【功能说明】 开场视频 - 启动游戏后播放自定义视频，播放结束后进入游戏菜单。 重绘菜单 - 主菜单、设置、开始游戏和暂停菜单全部替换为自定义界面。 - 按钮采用 iOS 风格动画：第一次点击选中，第二次点击打开。 原生地图按钮 - 在暂停菜单中增加「地图」按钮，调用游戏原生地图。 - 地图缩放、拖动和设置导航点保持原版操作方式。 - 进入和退出地图时带有黑场淡入淡出效果。 背景轮播 - 菜单和加载界面均支持设置多张背景图片。 - 背景自动淡入淡出，可自定义显示时间、切换时长和随机顺序。 动态加载画面 - 使用背景图与透明人物图层组合。 - 人物滑入后带有轻微漂浮动画。 - 右下角显示圆形加载进度条。 - 可设置加载界面的最短显示时间。 自定义音频 - 菜单背景音乐、点击/返回音效和加载音乐均可替换为自定义文件。 - 屏蔽原版菜单音效和加载音乐。 - 每次打开菜单时重新播放菜单音乐，切换到后台时自动暂停。 中文按钮文字 - 可通过 Labels.txt 修改按钮显示文字，支持自定义中文文本。 崩溃日志 - 游戏发生闪退时自动记录错误位置，便于收集日志和反馈问题。 【1.0 更新内容】 - 首个正式版本，新增 32 位版本（实验性）。 - 新增加载界面播放时长设置，可在 Loading.ini 中通过 min_time 调整。 - 修复使用地图后出现原版菜单和图标的问题。 - 修复设置界面变回原版菜单的问题。 - 修复原版点击音效未被屏蔽的问题。 - 修复部分旧系统机型因找不到 Java 环境，导致菜单回退为原版且没有声音的问题。 - 优化加载动画图片读取，减少卡顿。 - 菜单右下角增加版本和作者信息。 【1.1.0 更新内容】 - 修复进入「设置」界面后点击右下角位置会执行退回操作的问题。 - 重做按钮和动效，使整体视觉更符合大众审美。 - 地图界面左上角按钮新增背景效果，右下角新增版本号、作者信息等内容。 - 修复在「设置」界面点击内部按钮跳转时闪过原版地图的问题。 - 修复点击「继续游戏」后卡住、无法跳转的问题。 - 移除按钮第二次点击时的动画效果，减少跳转延迟。 - 优化按钮跟手逻辑。 - 修复在「设置」界面点击内部按钮会执行退回操作的问题。 - 移除点击屏幕时出现的波纹动画效果。 【兼容性】 - GTA SA Android 2.10：64 位。 - GTA SA Android 2.00：32 位（实验性支持）。 【注意事项】 当前版本可能仍存在其他问题。如遇到异常，请反馈问题并提供崩溃日志。 【作者信息】 作者：流王 哔哩哔哩：流王星者_Streamer
